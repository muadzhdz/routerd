# Unix Domain Socket IPC and Decoupled Daemon Architecture

We decouple the routerd background daemon from the interactive TUI dashboard via a streaming Unix Domain Socket IPC layer (`/run/routerd/routerd.sock`) with NDJSON framing and backpressure isolation. Previously, running the daemon required keeping a terminal session open or running headless with no way to inspect live telemetry or attached wireless stations. The IPC protocol allows unprivileged CLI invocations (`routerd status`, `routerd clients`, `routerd ping`) to query runtime state without touching root privileges or eBPF maps directly. Running `routerd` with no arguments automatically attaches the Bubbletea TUI to the live daemon stream, detaching cleanly on 'q' without interrupting routing. In addition, configuration is decoupled from CLI flags into `/etc/routerd/routerd.conf` with GNU double-dash and single-dash alias support.
