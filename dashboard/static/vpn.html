Quick Setup Guide
A Cloudflare WARP (automatic with wgcf)
Click "Generate WARP" above. If wgcf is installed, a real profile is generated automatically. Otherwise install wgcf first:
pacman -S wgcf # or go install github.com/ViRb3/wgcf/v2@latest
B Custom WireGuard VPS / Mullvad / ProtonVPN
Generate a keypair and paste into the editor above:
wg genkey | tee privatekey | wg pubkey > publickey cat privatekey # paste as PrivateKey in [Interface]
Minimum working config:
[Interface] PrivateKey = <YOUR_PRIVATE_KEY> Address = 10.2.0.2/32 [Peer] PublicKey = <SERVER_PUBLIC_KEY> Endpoint = <SERVER_IP>:51820 AllowedIPs = 0.0.0.0/0
C Existing VPN Interface (Tailscale, custom wg0, tun0)
Set VPN_MODE=custom and VPN_INTERFACE=wg0 in Configuration. routerd will use that interface as the NAT uplink without managing its lifecycle.
