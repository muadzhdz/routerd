Stealth & Anonymity Settings
Random MAC Address (RANDOM_MAC)
Generate a cryptographically randomized MAC for the AP interface on every start.
Host Isolation (ISOLATE_HOST)
Block connected AP clients from scanning, probing, or accessing local host services.
Prevent IPv6 Leaks (DISABLE_IPV6)
Disable IPv6 on AP interface & block IPv6 forwarding to prevent ISP location leaks.
Hide SSID Broadcast (HIDE_SSID)
Conceal the network name from regular Wi-Fi scans (hidden network mode).
WPA3-SAE Transition Mode (WPA3)
Enable WPA3-SAE authentication with backward-compatible WPA2-PSK transition support.
Tor Transparent Proxy (TOR_MODE)
Route all AP client TCP & DNS traffic transparently through local Tor daemon.
VPN Tunnel & Kill-Switch Settings
Enable Transparent VPN Gateway (ENABLE_VPN)
Automatically route all client traffic through an encrypted VPN tunnel.
VPN Kill-Switch (VPN_KILL_SWITCH)
Completely block client internet access if the VPN connection drops or fails.
Web Dashboard Daemon Configuration
Auto-Start Web Dashboard (DASHBOARD_ENABLED)
Automatically launch this web UI when routerd service starts.
